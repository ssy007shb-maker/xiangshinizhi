# 闻香识你 · 香调人格测试

一个面向校园场景的**香调人格测试**：8 道题，算出你的香调人格，并推荐 3 支真实存在的香水。

- **在线体验**：https://ssy007shb-maker.github.io/xiangshinizhi/
- **课程**：香水创新课 · 小组项目
- **技术**：单文件 HTML + 原生 JavaScript，零依赖、零外部图片（所有插画为内联 SVG）

## 这是什么

市面上的香水测评大多是「产品详情页」，人格测试又大多和气味无关。这个项目把两者的交叉点做成了一个产品：

> 把香水行业的**香族分类**（floral / woody / citrus …）翻译成普通人能回答的**行为题与气味直觉题**，测出「香调人格」，再从真实香水数据库里推荐匹配的香水。

## 玩法

1. 8 道选择题（从 24 道题库中随机抽取，选项顺序也随机）
2. 每题选项分别对应一个香族，累计得分
3. 得出主香族（香调人格）+ 次香族
4. 结果页展示：人设、香调画像（前/中/后调）、适合与避开、3 支推荐香水

## 8 种香调人格

| 人格 | 香族 | 主题色 |
|---|---|---|
| 阳光派 | 柑橘调 | 暖橙 |
| 温柔派 | 花香调 | 淡粉 |
| 元气派 | 果香调 | 莓红 |
| 独处派 | 木质调 | 棕 |
| 清透派 | 绿叶水生 | 墨绿 |
| 治愈派 | 甜香调 | 焦糖 |
| 神秘派 | 辛香东方 | 灰紫 |
| 沉稳派 | 粉感麝香 | 米灰 |

每种人格配有独立的视觉语言：页面背景色、卡片圆角软硬、标题字距都会变化。

## 数据来源

香水数据来自 [Scento Perfume Database](https://www.scento.com/perfume-database)，采用 CC BY 4.0 许可：

> Scento. Scento Perfume Database (2026-10-29). https://www.scento.com/perfume-database

推荐香水的筛选逻辑：按香族分组 → 取知名度排名靠前 → 人工筛选国内常见、适合学生价位的款式。

## 本地运行

直接双击 `index.html` 即可，不需要服务器、不需要联网。
